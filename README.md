# ceo-moneyup

เว็บแอปคำนวณและวางแผนเงินเดือนข้าราชการครู แบบ Mobile-first

## ฟีเจอร์
- เลือกอันดับ/วิทยฐานะ ครูผู้ช่วย–คศ.5
- กรอกเงินเดือนปัจจุบัน
- เลือกเปอร์เซ็นต์แบบปุ่มลัด 2.5 / 3 / 3.5 / 4%
- กรอกเปอร์เซ็นต์เองได้ สูงสุด 6%
- เลือกฐานคำนวณตามช่วงเงินเดือนอัตโนมัติ
- ปัดเงินเพิ่มขึ้นเป็นหลักสิบ
- แสดงเงินเพิ่ม เงินเดือนใหม่ และฐานคำนวณ
- จำลองอนาคต 1 / 3 / 5 ปี โดยใช้เปอร์เซ็นต์เดิมทุก 6 เดือน
- เก็บประวัติการคำนวณใน localStorage

## วิธีเปิด
เปิด `index.html` ได้โดยตรง หรือใช้ local web server เช่น

```powershell
cd D:\AI-Workspace\ceo-moneyup
python -m http.server 8080
```

จากนั้นเปิด http://localhost:8080

## หมายเหตุด้านข้อมูล
ฐานคำนวณในรุ่นต้นแบบนี้อ้างอิงตารางตามภาพตัวอย่างและหลักเกณฑ์ ก.ค.ศ. ว5/2562 ควรตรวจสอบประกาศล่าสุดก่อนใช้เป็นหลักฐานทางราชการ
